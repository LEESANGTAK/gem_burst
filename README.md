## 🎮 게임 소개
**《프리즘 크로스: 젬 버스트》**는 상·하·좌·우 4방향을 꿰뚫어 보는 직관적인 십자 매칭 퍼즐 메커니즘을 기반으로, 캔디크러시 스타일의 다채로운 10종 기하학 보석과 연쇄 폭발을 일으키는 특수 기믹 젬을 융합한 100% 독립 창작 IP 퍼즐 게임입니다.

* **저작권 & 법적 컴플라이언스**: '아이디어와 표현의 이분법'을 철저히 준수하여 상표, 그래픽, 사운드, 트레이드 드레스를 독자적으로 창작하여 법적 분쟁을 원천 차단했습니다.
* **100% 무손실 Web Audio API 신시사이저**: 외부 음원 파일 의존 없이 실시간으로 합성되는 우주 앰비언트 BGM과 다이내믹 크리스탈 효과음.
* **모바일 완벽 최적화**: 지연 없는 즉각 터치(`touch-action: none`), 기기 비율 적응형 디스플레이, 128px 고해상도 타일 캐시.

## ✨ 핵심 특징

### 1. 캔디크러시 스타일 10종 고유 보석 실루엣 (3D 쉐이딩 & 엠보스)
* 🔵 **사파이어 오브** (원형 구슬)
* 🔶 **토파즈 다이아몬드** (마름모)
* ❤️ **루비 하트** (하트)
* 🔺 **시트린 트라이앵글** (삼각형)
* 🟩 **에메랄드 큐브** (정사각형)
* ⭐ **다이아몬드 스타** (5각 별)
* 💧 **아쿠아마린 드롭** (물방울)
* 🔷 **아메지스트 펜타곤** (5각형)
* ⬡ **페리도트 헥사곤** (6각형)
* 🌸 **로즈쿼츠 플라워** (꽃잎/클로버)

### 2. 강력한 고대비 특수 기믹 젬 (Special Gems)
* 💣 **3x3 범위 폭탄 젬 (Area Bomb)**: 매칭 소거 시 폭탄 주변 3x3 영역(주변 8칸)의 모든 보석을 시원하게 날려버리는 범위 대폭발!
* ⚡ **체인 라이트닝 젬 (Lightning Spark)**: 소거 시 주변 보석들로 눈부신 체인 번개를 연결 발사하여 연쇄 감전 소거!
* ⏰ **타임 보너스 젬 (Time Plus)**: 매칭 시 남은 제한 시간을 즉시 +5초 연장!

### 3. 슈팅 게임 감각의 🔥 FEVER MODE
* 콤보를 이어 피버 게이지 100% 달성 시, 6초간 조준선에 걸리는 모든 보석을 색상 불문 일제히 쓸어 담는 광란의 초신성 피버 타임 발동!

### 4. 6가지 다채로운 게임 모드
* 🌟 **특수 젬 크러시**: 3x3 폭탄, 체인 번개, 타임 보너스가 연쇄 폭발하는 화려한 메인 모드 (23x15, 200타일)
* 🌌 **메가 버스트**: 1.5배 타일 대형 맵! 넉넉한 180초 동안 300개의 보석을 소거하는 메가 볼륨 (28x18, 300타일)
* ⚡ **아케이드 피버**: 콤보 게이지 100% 충전 시 초신성 불꽃놀이 피버 발동 (23x15, 120초)
* 🧘 **젠 / 힐링 모드**: 시간제한 없이 무제한 되돌리기(Undo)와 힌트로 즐기는 힐링 두뇌 퍼즐
* 🎯 **클래식 타임어택**: 순수 매칭 실력으로 도전하는 정통 타임어택 (120초)
* 🧩 **미니 퀘스트**: 모바일 한 손 플레이에 최적화된 쾌속 미니 보드 (15x10, 60초)
* 콤보를 쌓아 피버 게이지 100% 달성 시, 6초간 조준선에 걸리는 모든 보석을 전방향으로 폭파하는 광란의 피버 타임 발동!

### 5. 5대 게임 모드 지원
1. 🌟 **특수 젬 크러시 (Special Gems)**: 폭탄, 와일드, 번개, 타임 젬이 등장하는 전략적 모드
2. ⚡ **아케이드 피버 (120s)**: 스릴 넘치는 콤보와 피버 타임
3. 🧘 **젠 / 힐링 모드 (Zen Healing)**: 시간제한 없는 편안한 두뇌 퍼즐 (힌트 & 되돌리기 지원)
4. 🎯 **클래식 타임어택 (120s)**: 순수 두뇌 스피드 경쟁
5. 🧩 **미니 퀘스트 (15×10 / 60s)**: 가볍고 빠른 스피드런
