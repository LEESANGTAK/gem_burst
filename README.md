## 🎮 게임 소개
**《프리즘 크로스: 젬 버스트》**는 상·하·좌·우 4방향을 꿰뚫어 보는 직관적인 십자 매칭 퍼즐 메커니즘을 기반으로, 캔디크러시 스타일의 다채로운 10종 기하학 보석과 연쇄 폭발을 일으키는 특수 기믹 젬을 융합한 100% 독립 창작 IP 퍼즐 게임입니다.

* **저작권 & 법적 컴플라이언스**: '아이디어와 표현의 이분법'을 철저히 준수하여 상표, 그래픽, 사운드, 트레이드 드레스를 독자적으로 창작하여 법적 분쟁을 원천 차단했습니다.
* **100% 무손실 Web Audio API 신시사이저**: 외부 음원 파일 의존 없이 실시간으로 합성되는 크리스탈 타격음과 아케이드 신스 팡파레.

---

## ✨ 핵심 특징

### 1. 캔디크러시 스타일 10종 고유 보석 실루엣
* 🔵 **사파이어 오브** (원형 구슬)
* 🔶 **토파즈 다이아몬드** (마름모)
* ❤️ **루비 하트** (하트)
* 🔺 **시트린 트라이앵글** (삼각형)
* 🟩 **에메랄드 큐브** (정사각형)
* ⭐ **다이아몬드 스타** (5각 별)
* 💧 **아쿠아마린 드롭** (물방울)
* 🔷 **아메지스트 펜타곤** (5각형)
* ⬡ **페리도트 헥사곤** (6각형)
* 🌸 **로즈쿼츠 플라워** (꽃잎/클로버)

### 2. 산산조각 박살 파편 물리 연출 (Shatter Physics)
* 보석이 소거될 때 10~14개의 각진 크리스탈 파편 조각들이 "쨍그랑!" 소리와 함께 사방으로 튀어 올랐다가 중력으로 쏟아지는 압도적인 손맛.

### 3. 강력한 특수 기믹 보석 (Special Gems)
* 💣 **십자 폭탄 젬 (Cross Bomb)**: 해당 가로줄과 세로줄 전체를 레이저로 싹 쓸어버리는 대폭발!
* 🌈 **무지개 와일드 젬 (Wild Prism)**: 모든 색상·모양의 보석과 매칭되는 만능 조커!
* ⚡ **라이트닝 젬 (Lightning Spark)**: 무작위 4개의 보석을 번개로 원격 추가 저격!
* ⏰ **타임 보너스 젬 (Time Plus)**: 제한 시간을 즉시 +5초 연장!

### 4. 슈팅 게임 감각의 🔥 FEVER MODE
* 콤보를 쌓아 피버 게이지 100% 달성 시, 6초간 조준선에 걸리는 모든 보석을 전방향으로 폭파하는 광란의 피버 타임 발동!

### 5. 5대 게임 모드 지원
1. 🌟 **특수 젬 크러시 (Special Gems)**: 폭탄, 와일드, 번개, 타임 젬이 등장하는 전략적 모드
2. ⚡ **아케이드 피버 (120s)**: 스릴 넘치는 콤보와 피버 타임
3. 🧘 **젠 / 힐링 모드 (Zen Healing)**: 시간제한 없는 편안한 두뇌 퍼즐 (힌트 & 되돌리기 지원)
4. 🎯 **클래식 타임어택 (120s)**: 순수 두뇌 스피드 경쟁
5. 🧩 **미니 퀘스트 (15×10 / 60s)**: 가볍고 빠른 스피드런

## 🚀 실행 방법
별도의 번들러나 패키지 설치 없이 웹 브라우저에서 바로 실행할 수 있습니다:

```bash
# 로컬 웹 서버 실행 (Python 3)
python -m http.server 8080
```
브라우저에서 `http://localhost:8080` 접속
